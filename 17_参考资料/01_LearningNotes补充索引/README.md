# LearningNotes 补充索引

参考仓库：[francistao/LearningNotes](https://github.com/francistao/LearningNotes)

该仓库覆盖 Android、JavaSE、JVM、Java 并发、数据结构、算法、设计模式等内容。当前项目主要吸收其中和 Java 面试知识体系强相关的部分。

## 已整合内容

- 设计模式：补充面向对象设计原则，包括 SRP、OCP、LSP、DIP、ISP、LKP，以及组合优先于继承。
- 集合框架：补充集合体系结构、抽象骨架类、HashMap `put/get/resize` 源码阅读主线。
- Java 并发：补充线程创建方式、`wait/sleep` 区别、线程池源码主流程、生产者消费者实现方式。
- JVM：补充类加载生命周期、加载/验证/准备/解析/初始化、双亲委派模型。
- IO：补充 Java IO 中的装饰器模式和适配器模式。
