# 面试汇总

本目录用于整理高频场景题、项目复盘问答和答题方法论。

## 目录索引

| 文件 | 说明 |
|---|---|
| [`12_AI工程化场景题`](./12_AI工程化场景题/README.md) | 大模型流式输出、多模型路由、内容安全、Tool Calling、成本控制 |
| [`13_项目经验高频问答`](./13_项目经验高频问答/README.md) | 项目挑战、高并发、SSE、分布式锁、写后读一致性等 |
| [`14_面试作答方法论`](./14_面试作答方法论/README.md) | STAR、三段式答题、反问、简历准备清单 |

## 使用方式

先按场景题准备“技术方案”，再按方法论整理“表达方式”，最后把项目经历压缩成可复用的面试答案。
