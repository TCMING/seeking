# DAG 工作流引擎 ⭐

## 项目应用

`ibrain-prompt` 自研 DAG 工作流引擎，支持 LLM、MCP、HTTP、知识检索等节点。

## 核心考点

- 有向无环图（DAG）建模：邻接表 / 邻接矩阵
- 拓扑排序：Kahn 算法（入度表）、DFS 后序
- 节点依赖解析与并行调度：无依赖节点并行、依赖完成触发下游
- 节点失败处理：重试、跳过、熔断、回滚
- 异步节点挂起 + 回调恢复 + 断点续跑
- 工作流状态持久化：`workflow_runs`、`workflow_node_executions` 表，支持审计追踪与重放
- 超时控制与降级：`CostLimitServiceAdapter` 节点级超时

## 面试话术

> 在 ibrain-prompt 中，我们自研了 DAG 工作流引擎。核心流程是：**解析 DAG → 拓扑排序 → 并行调度无依赖节点 → 节点完成后触发下游 → 失败重试或熔断**。引擎支持异步节点挂起与回调恢复，节点状态持久化在 `workflow_runs` 和 `workflow_node_executions` 表里，方便审计和断点续跑。设计上每个节点类型抽象为策略，新增节点（比如新加 MCP 工具调用）只需实现执行策略接口，不影响调度核心。
