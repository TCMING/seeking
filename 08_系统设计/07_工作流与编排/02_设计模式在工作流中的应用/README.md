# 设计模式在工作流中的应用

## 项目应用

`ibrain-prompt` 工作流节点执行使用策略模式；`ibrain-base` 多模型接入使用工厂 + 适配器；`midjourney-proxy` 是代理模式典型实践。

## 核心考点

- **策略模式**：节点类型（LLM/MCP/HTTP/知识检索）执行策略解耦
- **工厂模式**：按模型类型选 Service 实现，新增模型零侵入
- **适配器模式**：统一不同模型 / 语音 / 插件协议
- **生产者-消费者**：流式消息、异步任务处理
- **代理模式**：midjourney-proxy 把 Discord 长连接 HTTP 化
- **观察者模式**：Spring Event 事件驱动
- **责任链模式**：拦截器、过滤器链、内容审核多级检测
