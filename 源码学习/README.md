## 阅读建议

1. **先看路径，再动手跑**：每篇路径文档第一阶段都是跑通最小可运行示例，跑不通的源码再多读也没用。
2. **自顶向下**：从业务入口（example / starter）切入，沿调用链逐层下沉，避免一上来就钻底层。
3. **边读边记**：在子目录下按编号建立笔记（如 `01_架构总览.md`、`02_主流程时序图.md`），与 `seeking/13_项目经验高频问答/` 对应起来，方便面试复盘。
