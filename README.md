# Java 面试知识点目录

在线阅读地址：<https://tcming.github.io/seeking/>

本项目目录参考 `D:\project\ibrain\docs\06_Java面试知识点总结.md` 构建。

当前结构按文档章节拆分：

- 一级目录对应文档 `##` 章节
- 二级目录对应文档 `###` 小节

后续可以在各子目录中继续补充：

- 知识点笔记
- 示例代码
- 高频问答
- 复习清单

新增扩展模块：

- `02_数据结构和算法`：数据结构、算法和常见题型
- `03_数据库`：MySQL、Redis、ShardingSphere
- `04_消息队列`：RocketMQ 和消息队列常见问题
- `05_设计模式`：整理 Java 面试中高频设计模式及项目落地场景
- `06_工程框架`：源码学习、运行手册、工程化实践
- `07_面试汇总`：AI 工程化场景题、项目高频问答、答题方法论
- `08_系统设计`：工作流、稳定性、分布式、任务调度、可观测性
- `09_AI工程`：预留给后续 AI 专题内容
- `10_参考资料`：记录外部学习资料与当前目录的整合索引
- `11_附录`：知识点映射与补充清单

## 在线阅读

本仓库已支持 GitHub Pages 在线阅读，使用 `MkDocs Material` 构建。

部署方式：

- 推送到 `master` 后，GitHub Actions 会自动构建站点。
- 站点发布到 `https://tcming.github.io/seeking/`。
- GitHub 仓库需要在 `Settings -> Pages` 中选择 `GitHub Actions` 作为发布来源。
